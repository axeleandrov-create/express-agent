# На что ставить (express-agent)

Лента одинаров, экспрессы, LIVE-купоны. Сборка **2708c**.

## Локально (компьютер)

```
start.bat
```

Откроется http://127.0.0.1:3006/

## Ссылка на телефон (пока комп включён)

```
share-link.bat
```

## GitHub + постоянная ссылка в облаке

1. Запусти **`publish-github.bat`** — зальёт код на GitHub (нужен вход один раз).
2. На [Render Deploy](https://render.com/deploy) подключи этот репозиторий — Render прочитает `render.yaml` и даст ссылку вида `https://express-agent-xxxx.onrender.com`.
3. Эту ссылку открывай в Safari на телефоне — работает из любой сети.

> GitHub хранит код. Сам сайт с данными крутится на Render (бесплатный тариф). GitHub Pages для этого проекта не подходит — нужен сервер.
